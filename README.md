# Code for Dynamics Project 3

This repository contains code for the 3rd dynamics project of AE 2220. This code was created in MATLAB. Please read these instructions all the way through to download it.

## How to Download the Project 3 Code
1. Make sure you have a copy of MATLAB installed on your computer.
2. Click the green "download" in the top right corner.
3. This will download a .zip file. Unzip this file into a safe folder.
4. In the unzipped folder, open whatever file you'd like to work on.
5. To execute entire project, open and run `dynamicsProject3.mlx`
